About

Boring Tools is a collection of 35 free browser-based utilities built by a developer with 15+ years of web development and software engineering experience. Every tool is designed to solve one problem well — no accounts, no pop-ups, no tracking.

All tools run entirely on your device using native browser APIs (Web Crypto, TextEncoder, FileReader). Nothing you type or upload is ever sent to a server. The site is built with plain HTML, CSS, and JavaScript — no frameworks, no build step, no third-party dependencies beyond CDN libraries for QR codes and Markdown rendering.

The source code is open on GitHub, the site is hosted on GitHub Pages, and it costs effectively nothing to run — so it won't disappear behind a paywall.

Have an idea or found a bug? Open an issue on GitHub.
